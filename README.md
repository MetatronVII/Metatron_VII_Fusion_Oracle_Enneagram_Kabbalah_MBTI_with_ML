Metatron VII Fusion Oracle: Enneagram-Kabbalah-MBTI with ML
Overview
This project is a Python script that fuses Kabbalah (Sephiroth), Enneagram types, and MBTI soul levels using Machine Learning (Random Forest) to predict spiritual-digital personality fusions. Inspired by mystical traditions and AI ethics, it generates synthetic data with correlation rules, trains a multi-output model, and outputs poetic visions via xAI API. Ideal as an MVP for oracle apps on Google Play.
Features

Synthetic data generation with mystical rules (e.g., high analysis → Binah + Type 5 + Neshamah).
Modular structure for easy expansion (multi-output predictions).
Poetic outputs using xAI for inspirational insights.
Ethical safeguards: Environment variables for API keys, balanced datasets.

Requirements

Python 3.12+
Libraries: numpy, pandas, scikit-learn, openai (install via pip install -r requirements.txt)
xAI API key: Set as environment variable XAI_API_KEY (sign up at https://x.ai/api)

Usage

Clone the repo: git clone https://github.com/yourusername/metatron-vii-fusion-oracle.git
Set API key: export XAI_API_KEY=your_key
Run: python fusion_oracle.py

Trains model and prints example prediction.


Customize: Expand rules in generate_synthetic_data or integrate into Flask for web apps.
