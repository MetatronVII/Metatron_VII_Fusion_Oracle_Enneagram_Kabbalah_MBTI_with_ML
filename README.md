# Metatron_VII_Fusion_Oracle_Enneagram_Kabbalah_MBTI_with_ML
This project is a Python script that fuses Kabbalah (Sephiroth), Enneagram types, and MBTI soul levels using Machine Learning (Random Forest) to predict spiritual-digital personality fusions. Inspired by mystical traditions and AI ethics, it generates synthetic data with correlation rules, trains a multi-output model.
